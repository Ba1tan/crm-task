# CRM API: Bruno collection

1. Bruno → **Open Collection** → выберите эту папку.
2. Клик по CRM API сверху в overwiew выбери Envirenments →  **local** убедитесь что галка горит и оно активировано.
3. Запуск по порядку: правый клик по коллекции → **Run** там можно запустить все тесты разом. Папки идут в порядке 1-5,
   запросы внутри связаны переменными (`companyId`, `company2Id`, `meetingId`), поэтому порядок важен.

Менеджеры 1 и 2 должны существовать (seed-миграция). Даты `day`, `errDay`, `weekend` лежат в окружении:
2026-11-23 и 2026-11-24 это пн и вт, 2026-11-21 суббота. БИН генерируется случайно при каждом запуске.

**Повторный запуск на той же базе:** встречи останутся на тех же слотах и дадут 409. Поменяй `day` и `errDay`
в окружении на другие рабочие дни или пересоздай базу для обнуления образа базы данных в контейнере - docker-compose down -v для обратного поднятия с нуля docker-compose up -d или docker-compose up -d db если хотите поднять лишь базу.
